Calculator Web Application

Built a responsive calculator using HTML, CSS, and JavaScript. The calculator performs basic arithmetic operations such as addition, subtraction, multiplication, and division. It includes a user-friendly interface, clear and delete functionality, real-time display updates, and keyboard support for improved usability.

Technologies Used:

HTML
CSS
JavaScript

Features:

Basic arithmetic operations
Clear and delete functions
Keyboard support
Responsive UI design
Real-time result display
